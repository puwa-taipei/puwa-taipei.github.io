# 原話接招室：百分之幾的沈委員？

這是一款瀏覽器對話配對遊戲，來自讀者提出的玩法：玩家在模擬對話中，從幾句沈伯洋原話選一句回應，結束後看配對得分。

## 情境與原話

- 對話角色與提問是虛構創作，不是實際對話紀錄。
- 三個選項都來自本站既有的沈伯洋原話典藏。正解依原始議題對應，並非判定某句有沒有說過。
- 每輪六題、六個不同事件，從二十個情境抽出。回饋與結算提供原始日期、語境、來源品質與連結。
- 「百分之幾的沈委員」是本輪配對成功題數除以六、乘一百後四捨五入的趣味分數；不是人格、平日言論頻率或政治立場測量。
- 引文保留典藏中的來源品質標示；未核聽原音者不宣稱已逐句核聽。

## 公開程式碼

原始碼位於 [puwa-taipei/puwa-taipei.github.io](https://github.com/puwa-taipei/puwa-taipei.github.io/tree/main/game/dialogue)。遊玩入口是 [puwa.taipei/game/dialogue/](https://puwa.taipei/game/dialogue/)。這款遊戲共用原網站，不需要額外的儲存庫、伺服器或資料庫。

- `index.html`、`dialogue.css`：獨立頁面與手機版樣式。
- `dialogue.js`：介面、來源展示、同題連結與使用者主動分享。
- `core.js`：確定性抽題、去重事件、選項與計分狀態機，可在 Node.js 載入測試。
- `rounds.json`：情境與原話 ID，不修改原始典藏。
- `cover.png`：以程式繪製的固定分享封面。連結預覽不宣稱帶有伺服器認證的個人成績。

## 資料與隱私

遊戲讀取 `/data/quotes.json`，並以 `rounds.json` 固定的 SHA-256 核對來源版本。不收集名字、Email、答案或個人分數；不呼叫投稿或排行榜 API。分享網址只含可重現同一輪的亂數種子，沒有答案與玩家身分。使用者按下分享後，才開啟裝置分享或複製成績與連結。

## 投稿與製作

這個原型示範「提出玩法 → 人工挑選 → 製作 → 核對來源與測試 → 上架」的路徑。投稿不會自動製作、執行或上架。後續新遊戲仍需個別核對來源、程式碼、授權及第三方服務。
