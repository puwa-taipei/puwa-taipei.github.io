# 國會紀錄與公開政策對照

本網站整理沈伯洋自 2024 年 2 月 1 日上任後的法律提案、委員會與審議流程、公開言論及競選政策，提供圖表、逐案檢索、原文連結與 Obsidian 知識庫下載。主提案、共同提案與連署分開計數；議題分類、比較方法與資料限制均在網站及知識庫中說明。

資料與政策頁快照的更新截止日：**2026 年 10 月 20 日**。這是可取得資料的快照，不保證上游已收齊截至當日的所有紀錄。

## 來源與署名

- [立法院議事暨公報資訊網](https://ppg.ly.gov.tw/ppg/)及立法院官方法律提案 API、iVOD：提案、議事、公報與影片紀錄。
- [OpenFun LYAPI](https://ly.govapi.tw/v2/)：本次議案與流程資料的主要民間彙整來源，官方提案資料另作交叉核對。
- [候選人競選官網](https://puma.taipei/policies)：政策頁原文來源。
- 言論資料逐筆保留官方逐字稿、本人文章或媒體原文連結，相關內容權利歸各來源。本次未使用 Acta 作全量語料，Twinkle 僅查公開文件；工具介紹與授權要求另見知識庫。

分類、計算與整理為本研究所作，不代表資料提供者背書。引用時請保留來源、截止日、角色定義及資料限制。
