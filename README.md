原話投稿只需原句與主要來源網址；遊戲投稿只需名稱、簡介與公開GitHub儲存庫。其餘資訊與署名／私人聯絡方式各收在預設折疊的選填區，投稿同意仍需勾選。有填的選填欄位仍驗證格式；錯誤會展開對應區塊。遊戲上架前仍須由管理員補核完整提交、授權、外部服務與素材權利，並明確確認發布。原稿已有提交不得更換；空白才可補核。私人權利快照不進公開清單。
