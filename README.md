每則保留日期、場合、短引文、前後文、來源位置與解讀限制。官方逐字稿、本人署名文章、當日媒體直接引述分別標示；書面不當作現場口說。官方文字稿核對不代表已核聽影片，未核聽的句子不附編造秒數；同場前段參照影片也明確標示，不冒充該句的原片位置。

正式提名比較切點為 2026-05-13，全庫提名前 112 段、提名日起 16 段。這是編輯選樣，不能用題目比例推估平日語氣、全部政策立場、支持者認知或人格真假。個別政治指控不等於司法認定。網站同時保留普通政策與不同面向的材料。
