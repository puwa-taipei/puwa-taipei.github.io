## v30 遊戲點子投稿與原話接招

點子與聯絡方式不會出現在公開遊戲清單。完成的遊戲仍須以作品類型提交，補齊公開原始碼、固定版本、授權與素材權利，通過審核並確認發布後才列入社群清單；點子本身不能直接發布成遊戲。私人審核維持既有管理員登入與權限。

新增 [原話接招：換你當沈委員](https://puwa.taipei/game/dialogue/)。聊天情境為虛構創作，選項取自附來源的真實原話，並非當時對話重演。「百分之幾的沈委員」是本輪原話配對的趣味分數，不能作為人格或日常言論分布的測量。完成後可逐題回顧來源、重玩與分享。

兩站的遊戲庫仍共用同一份目錄；遊戲程式公開於本儲存庫，不必為每個初期點子另建帳號或儲存庫。新遊戲的原創程式授權與第三方引文界限見 `game/dialogue/LICENSE`。
